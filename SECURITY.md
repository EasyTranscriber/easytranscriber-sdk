# Security

Report suspected vulnerabilities privately to [info@easytranscriber.com](mailto:info@easytranscriber.com). Include the affected SDK or integration, version or commit, impact, and a minimal reproduction using dummy credentials and sanitized data.

Do not disclose vulnerabilities or credentials in public issues, pull requests, workflow exports, logs, or screenshots. Never send API keys, bearer tokens, passwords, or private transcription content in a report. Redact sensitive values before sharing evidence.

If a credential has been exposed, revoke or rotate it promptly through the service that issued it. Removing it from a file does not invalidate it or remove existing copies.

Please coordinate public disclosure privately so maintainers can investigate and prepare a fix. This repository does not promise a response deadline.
